# Sahlvert (سهل فرت) updates

Download the installer: [Sahlvert-Setup.exe](https://raw.githubusercontent.com/fy0-7/dropconvert-updates/main/Sahlvert-Setup.exe)

Sahlvert was called DropConvert before version 2.4.0.
Installed copies check `latest.json` here every day and install new versions automatically.
Every update is signed; the app refuses anything that isn't.
