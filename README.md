# Seeghati (صيغتي) updates

Download the installer: [Seeghati-Setup.exe](https://raw.githubusercontent.com/fy0-7/dropconvert-updates/main/Seeghati-Setup.exe)

Seeghati was called Sahlvert (2.4) and DropConvert (before 2.4). Installed copies update to Seeghati by themselves.
Installed copies check `latest.json` here and install new versions automatically.
Every update is signed; the app refuses anything that isn't.
